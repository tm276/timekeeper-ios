# TimeKeeper iOS

A time tracking app for freelancers and consultants. Track time per client, sync to Nextcloud or Google Drive, and get location-aware reminders when you start the wrong client timer.

## Features
- Per-client time tracking with CSV export
- Weekly CSV windowing
- Nextcloud and Google Drive sync
- Location-based client site detection
- Work site management

## Building
Requires [xtool](https://github.com/xtool-org/xtool) and Swift 6.2+.

```bash
xtool dev
```
